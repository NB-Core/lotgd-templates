A nostalgic bundle of the original HTML/CSS themes that once shipped with the **Legend of the Green Dragon** engine. These templates are old-school, occasionally crusty, yet still perfectly capable of giving your game that classic LoTGD charm.

## What’s inside?

- Dozens of historical themes like **Classic**, **Cupertino**, **Redmond**, and more.  
- Each template pairs a `.htm` layout with matching `.css` styles.  
- No modern bells and whistles—just retro web magic.

## Using the templates

1. Copy a template’s `.htm` and `.css` files into your LoTGD installation’s `templates/` directory.  
2. Select it from your game’s settings or configuration.  
3. Enjoy the throwback aesthetic (and feel free to polish it up).

## Contributing

These templates work, but many could use modernization or cleanup. If you’re feeling brave, grab a template, refactor it, and open a pull request. Bonus points for responsive layouts and accessibility tweaks!
